# Vaultrum

**Vaultrum** es un vault abierto de conocimiento, criterio y trabajo con inteligencia artificial orientado al desarrollo de videojuegos, software y sistemas creativos.

El proyecto está pensado para abrirse principalmente en **Obsidian** y usarse como una base de conocimiento navegable mediante archivos Markdown, carpetas y wikilinks.

---

## Entorno recomendado

Para usar Vaultrum se recomienda tener instalado:

- **Obsidian**, para abrir y navegar el vault.
    
- **Git**, para clonar o versionar el repositorio.
    
- **GitHub**, si se quiere trabajar con forks, issues o pull requests.
    

Opcionalmente, para trabajar con IA sobre el contenido del vault, se puede usar cualquier herramienta capaz de leer archivos Markdown y trabajar con contexto local.

---

## Cómo abrir Vaultrum

1. Leer este `README.md`.
    
2. Descargar o clonar este repositorio.
    
3. Abrir Obsidian.
    
4. Elegir la opción **Open folder as vault**.
    
5. Seleccionar la carpeta raíz de Vaultrum.
    
6. Abrir `00_START_HERE.md`.

## Definición

El **lenguaje de formas** (*shape language*) es la lectura que el ojo hace de las formas básicas antes de cualquier detalle. Un diseño construido sobre una forma dominante comunica su carácter de un vistazo.

```txt
circulo      amable, blando, seguro, juguetón
cuadrado     estable, fuerte, confiable, pesado
triangulo    dinamico, peligroso, agresivo, inestable
```

Son tendencias de lectura, no leyes: un círculo puede ser amenazante si es enorme y oscuro. Pero cuando un diseño va contra su forma, lo hace a propósito.

## Idea central

```txt
una forma dominante      decide el caracter
formas de apoyo          lo matizan
variedad de tamanos      grande, mediano y chico: un diseno con todo del mismo tamano
                         se ve plano
```

## Especificación para videojuegos

```txt
vale para todo lo que se lee   personajes, enemigos, torres, objetos que se agarran.
                               Una torre de defensa en triangulos se lee como ataque; en
                               cuadrados, como muro
codifica la funcion            si los peligros son punzantes, el jugador aprende a leer
                               punzante = peligro. Se sostiene en todo el juego
se suma a la silueta           la forma dominante es lo que hace distinta una silueta de
                               otra
```

## Cómo se juzga

```txt
se juzga    si la forma dominante dice el caracter que pide el diseno. No hay instrumento
            y no se finge
se mide     lo que la forma produce: la silueta (Silueta legible)
```

## Errores comunes

```txt
Un enemigo amable de formas punzantes, sin que nadie lo haya decidido.
Todas las formas del mismo tamano.
Cambiar el lenguaje de formas entre familias del mismo bando.
```

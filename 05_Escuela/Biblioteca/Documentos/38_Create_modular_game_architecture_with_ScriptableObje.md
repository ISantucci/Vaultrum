- **Qué se aprende:**
  - ScriptableObjects como **arquitectura**, no como contenedor de datos: eventos, variables compartidas, runtime sets.
  - Desacople de sistemas sin singletons ni referencias duras — resuelve el problema clásico de managers acoplados.
  - Reducción de uso de memoria y agilización del flujo de trabajo, según el planteo de Unity.
  - Viene con proyecto de muestra en la edición Unity 6.
- **Gap de Vaultrum que cubre:** patrón concreto de desacople para managers y sistemas en los proyectos Unity de Vaultrum.

# Documento 39 — Unity — Best practice guides (manual oficial)

> Artefacto real de la industria, catalogado para consulta del Productor y de Game Design.
> **IP:** ficha + referencia. La Biblioteca no aloja ni reproduce el documento original.

---

- **Autor / estudio y año:** Unity Technologies, documentación viva (versión 6000.3 consultada)
- **Tipo:** Doc técnica oficial
- **URL:** https://docs.unity3d.com/6000.3/Documentation/Manual/best-practice-guides.html (**fetcheada OK**)
- **Estado de acceso:** El portal de documentación es **público y libre**; varias de las guías enlazadas son e-books que piden registro.
- **Qué se aprende:**
  - Es el **índice maestro** de todo el material de buenas prácticas de Unity, en cinco ejes: Arte y Diseño, DevOps, Gráficos y Rendering, Optimización de Rendimiento y Scripting.
  - En Scripting: estándares de C#, arquitectura de multijugador, DOTS, patrones con ScriptableObject, SOLID y patrones de diseño.
  - En Optimización: móvil, XR, web, consola y PC, profiling y gestión de memoria — cubre el e-book de optimización que se pedía en el brief.
  - En Arte y Diseño: fundamentos de level design y prototipado de game design — material directamente útil para el Área de Level Design.
  - En DevOps: organización de proyecto y control de versiones, que encaja con el modelo git de Vaultrum.
- **Gap de Vaultrum que cubre:** una sola URL que indexa el corpus completo de buenas prácticas Unity; ingesta de alto rendimiento.
- **Prioridad:** **Alta — punto de entrada recomendado para la familia Unity**

# Documento 30 — DOOM — source release

> Artefacto real de la industria, catalogado para consulta del Productor y de Game Design.
> **IP:** ficha + referencia. La Biblioteca no aloja ni reproduce el documento original.

---

- **Autor / estudio y año:** id Software, código de 1993, liberado en 1997
- **Tipo:** Código fuente
- **URL:** https://github.com/id-Software/DOOM · Copia histórica: https://archive.org/details/Doom_source_GPL · Contexto: https://en.wikipedia.org/wiki/Doom_engine
- **Estado de acceso:** Libre, **GPL**.
- **Qué se aprende:**
  - BSP para visibilidad en 2.5D: la solución algorítmica que hizo posible el juego en el hardware de la época.
  - Formato WAD: separación estricta entre código y datos, y el origen del modding como práctica.
  - Sistema de "thinkers" para actualizar entidades — un patrón de game loop que sigue siendo legible hoy.
  - Su lectura se complementa perfecto con la Doom Bible: **el documento que se descartó y el código que sí se hizo**, lado a lado.
- **Gap de Vaultrum que cubre:** el par documento-código del mismo proyecto; caso único en la Biblioteca.

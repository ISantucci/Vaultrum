# Documento 29 — Quake — GPL source release

> Artefacto real de la industria, catalogado para consulta del Productor y de Game Design.
> **IP:** ficha + referencia. La Biblioteca no aloja ni reproduce el documento original.

---

- **Autor / estudio y año:** John Carmack — id Software, código de 1996, liberado en 1999
- **Tipo:** Código fuente
- **URL:** https://github.com/id-Software/Quake (**fetcheada OK**)
- **Estado de acceso:** Libre, **GPL**. Licencia explícita — de lo más limpio del relevamiento. Los assets originales no se pueden redistribuir.
- **Qué se aprende:**
  - Incluye WinQuake, GLQuake, QuakeWorld y GLQuakeWorld: **cuatro variantes del mismo juego** para comparar decisiones de rendering y red.
  - **QuakeC**: un lenguaje de scripting propio para la lógica de juego, separado del motor en C. Es el antecedente directo de la separación engine/gameplay que hoy dan por sentada Unity y Unreal.
  - Archivos en assembly para el renderer por software: qué significaba optimizar antes de la GPU.
  - QuakeWorld como rediseño de red con predicción del cliente — fundacional para todo el multijugador moderno.
- **Gap de Vaultrum que cubre:** separación motor/gameplay y fundamentos de netcode, con licencia inequívoca.
- **Prioridad:** **Alta**

# Documento 53 — Game UI Database

> Artefacto real de la industria, catalogado para consulta de UI/UX y de Game Design.
> **IP:** ficha + referencia. La Biblioteca no aloja ni reproduce las capturas.

---

- **Autor y año:** Edd Coates, desde 2020; versión 2.0 con más de 55.000 capturas
- **Tipo:** base de datos de referencia visual, filtrable
- **URL:** https://www.gameuidatabase.com/
- **Estado de acceso:** **Libre y sin registro.** Las capturas pertenecen a los juegos que documentan; la base es un índice, no una redistribución de assets.
- **Qué se aprende:**
  - Catálogo de pantallas de juegos reales, **filtrable por tipo de pantalla** (título, pausa, inventario, mapa, opciones, referencia de controles) y por género, plataforma y año.
  - Permite responder empíricamente la pregunta que un dev solo no puede responder de memoria: *¿qué pone la gente en una pantalla de pausa?* — y ver cincuenta respuestas en un minuto.
  - Cubre las pantallas que los libros de UI ignoran: la de opciones, la de referencia de controles, la de "sin conexión". Son exactamente los "estados de UI olvidados" que `14_UI_HUD_y_menus` nombra.
- **Gap de Vaultrum que cubre:** `14_UI_HUD_y_menus` da baselines numéricos y principios, pero **no tiene ni una referencia visual**. Este es el catálogo contra el cual contrastarlos.
- **Prioridad:** **Alta** — es la consulta más barata y directa del estante para un `UXS`.
